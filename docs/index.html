二批注 / ANNOTATION

拿起笔就写，
就像在真正的书页上

这不是一个「模仿」原生体验的阅读器——你读书用的就是 reMarkable 的原生阅读器。所以落笔的那一瞬间没有任何折扣：笔尖到墨迹的延迟、纸张般的摩擦感，和你写笔记本时一模一样。

在页边写下的批注、划出的重点、画的图，都是设备里堂堂正正的手写内容——可以导出，可以同步，永远跟着这本书。

你的笔迹，永远安全

书的内容更新时，已经写过批注的页面绝不会被覆盖。新版本会作为一本单独的「(更新版)」出现，你写下的每一笔都留在原处。

四读原版 / IN THE ORIGINAL

为读英文原版而生：
查词不打断，查过不白查

读原版最大的敌人从来不是词汇量，是每一次查词造成的中断，和查完第二天就忘的挫败。这两件事，各用一个功能解决。

圈词即译 / CIRCLE TO TRANSLATE笔不离手，
心流不断

读到不认识的词，用笔把它圈起来：释义、英文例句、例句的中文翻译，一起出现在这一页上。看完点掉，页面还是那一页。

整句读不通也一样——圈住一整段，中文就浮在旁边。不切换应用、不弹出键盘、不跳去别处，让查词便宜到几乎没有代价。

而且微信读书的原版书本身常常就是中英对照的：一段英文，一段中文，答案就在下面。

遗忘曲线：为什么要在特定的时点复习
查完不复习 按曲线复习

原理示意图。每复习一次，记忆重新拉满，下一次滑落得更慢——所以间隔可以越拉越长。

遗忘曲线复习 / SPACED REPETITION在你快要忘记的
那一刻，再见一面

每个圈过的词都进入生词本，然后按艾宾浩斯遗忘曲线安排重逢：先隔一天，再隔几天，然后是一周、半个月——每次都赶在记忆滑落之前把它拉回来，间隔越拉越长，直到这个词真正属于你。

复习时给你看的不是孤零零的单词，而是一句用得上的例句。词义长在句子里，才记得牢。

每天几分钟，读完一本原版书，顺便收获几百个真正记住的词。

五承诺 / OUR PROMISES

简单，
而且只属于你

没有第三方服务器

你的账号和书只经过微信读书和你的设备，中间没有任何人经手。不注册、不收集、不上传。

不打扰你的账号

它安安静静地只做「读」这一件事：不替你标进度、不替你发想法，你的微信读书账号保持原样。

开源，免费

全部代码公开在 GitHub 上，任何人都可以审阅它做了什么、没做什么。没有付费墙，没有订阅。

克制地使用网络

只在需要时拉取需要的内容，对微信读书的服务器保持礼貌——这也是它能长久稳定使用的原因。
